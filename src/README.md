# React Quiz Application

A responsive multiple-choice quiz application built with React. Users can navigate through questions, select answers, see instant feedback (correct/wrong), read explanations, and jump to any question using the interactive navigation panel.

## 🛠 Technologies Used

- **React** (with Vite) - Frontend library and build tool
- **JavaScript (ES6+)** - Logic and state management
- **CSS3** - Responsive styling and layout
- **React Hooks** (`useState`) - State management for questions and answers

## ✨ Features

- Multiple-choice quiz with 8 unique questions
- Instant visual feedback (green for correct, red for wrong)
- Detailed explanation shown after answering each question
- Interactive sidebar with numbered buttons to jump between questions
- Visual indicators for current, answered, and unanswered questions
- Prev / Next navigation buttons
- Fully responsive design (works on desktop and mobile)
